# 申告書様式のレイアウト校正ツール

国税庁「相続税の申告書等の様式一覧（令和8年分用）」の一括印刷用PDF（一般用）は、各ページが300dpiの画像で、
入力欄（AcroForm）を持たない。そこで次の手順で「どこに何を書くか」を決める。

1. `extract_pages.py` で各ページを白黒PNGにして `public/forms/r08/` へ保存する。
2. `fields/*.json` に、入力欄の内側の1点（seed、300dpi画像のピクセル座標）と書式を書く。
3. `calibrate.py` が seed から罫線で囲まれた領域を塗りつぶして欄の矩形を求め、
   `src/forms/r08/layout.json`（PDF座標・pt）を生成する。確認用のプレビュー画像も出力する。

seed 方式なので、罫線の位置を手で測る必要がなく、様式の改訂時も seed を見直すだけで済む。
