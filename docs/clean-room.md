# クリーンルーム開発の方針

相続コンパスは、開発者が過去に作ったアプリ（税理士向けの相続税申告・財産管理アプリ）とは**別にゼロから**実装しています。

## 守っていること

- 既存プロジェクトのソースコード・内部実装を、コピー・流用・移植しない。AI に書き直させて実質的に再利用することもしない
- 既存プロジェクトから参考にするのは、業務上の課題、ユーザー体験、税務上の論点、過去の不具合から得た知見、検証すべき条件だけ
- 計算方法やアルゴリズムは、国税庁・国土地理院などの公開資料を根拠に、今回新たに設計・実装する
- 既存の独自仕様・アルゴリズムと実質的に同じになるおそれがある設計は、採用前に報告して判断を仰ぐ

## 主な根拠資料

| 機能 | 根拠 |
| --- | --- |
| 相続人と法定相続分 | 民法 887条・889条・890条・900条・901条・939条 |
| 基礎控除・税率・按分・2割加算・各種税額控除 | 相続税法 15条〜19条の4、相続税法基本通達 17-1 |
| 生命保険金等の非課税 | 相続税法 12条 |
| 小規模宅地等の特例 | 租税特別措置法 69条の4 |
| 奥行価格補正率 | 財産評価基本通達 付表1 |
| 区分所有補正率 | 居住用の区分所有財産の評価について（法令解釈通達）、国税庁タックスアンサー No.4667 の計算例 |
| 申告書の様式・記載方法 | 国税庁「相続税の申告書等の様式一覧（令和8年分用）」「相続税の申告のしかた」 |
| 路線価図の読み方 | 国税庁「財産評価基準書 路線価図・評価倍率表」の説明 |
| 地図・住所検索 | 国土地理院 地理院タイル、住所検索API、逆ジオコーダ |

## 既存アプリと異なる設計にした点

- **対象者**：税理士ではなく一般の納税者。専門用語を言い換え、Claude の案内と7ステップで迷わず進めるようにした
- **路線価図の地図重ね表示**：既存アプリが採っていた「索引図から図郭を自動推定する」方式は採らず、利用者が路線価図と地図で同じ地点を2〜3か所選び、そこから相似変換・アフィン変換を求める方式を新たに設計した（`src/domain/geo/georef.ts`）
- **申告書の PDF 化**：国税庁の様式 PDF を画像化し、欄の位置を塗りつぶし探索で校正するツール（`scripts/forms/calibrate.py`）を作り、計算結果を重ねて記入する
- **計算の厳密さ**：按分割合などを BigInt の分数で計算し、端数処理は条文・通達どおりの位置でだけ行う
